Put your game data here. OpenSWOS includes nothing from the original game.

1. On a PC or Mac, run OpenSWOS Setup with your copy of the game: the GOG PC
   version, the Amiga .adf floppies, or both. Press Install.
2. Copy everything in the folder it filled into this folder:

     Windows  Documents\SWOS\assets
     macOS    ~/Library/Application Support/SWOS/assets
     Linux    ~/.swos/assets

ASSETS.ini must end up directly in this folder, next to this file.
